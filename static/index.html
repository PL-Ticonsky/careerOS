Conectar Google Places

Prepara tu proyecto en Google Cloud. Estas consultas pueden generar cargos: configura límites y alertas en tu cuenta.

  1. Crea un proyecto de Google Cloud ↗, o selecciona uno existente.
  2. Vincula la facturación ↗. Revisa las condiciones y los costos en tu cuenta.
  3. Habilita Places API (New) ↗ en ese proyecto.
  4. Crea una clave de API ↗ y limítala a Places API (New).

Introduce la clave aquí, en tu equipo. Se guarda en un archivo privado local, separado de los respaldos de oportunidades.
